# UGJProject — 착한 마녀의 행운 가게 (가제)

> **Official Unity Game Jam 2026** 출품작 (2D)
> 게임 타이틀: **TBD** · 잼 주제: **TBD**

판타지 세계의 손님이 남기는 힌트(예: "내 행운의 숫자는 7이야")를 추리해서,
착한 마녀가 운영하는 행운 가게의 물품을 드래그앤드롭으로 담아 건네는 2D 가게 운영 게임입니다.

## 🎮 게임 개요 (초기 기획 기준, 확정 시 갱신)

**하루 루프**

1. 하루 시작 (현실 시간 **5분**)
2. 손님 방문 → 텍스트 힌트 제시, 인내심 게이지 감소 시작
3. 플레이어가 힌트를 추리해 행운 물품을 **드래그앤드롭**으로 배치 (예: 사탕병, 숫자 스티커, 도형 조각)
4. 검사 → 맞으면 **팁**, 틀리면 **환불** (UI는 팁 유무로 표시)
5. 하루 끝 → **업그레이드** 구매 (예: 테이블, 서머타임, 사탕 분류)
6. 다음 날

**승패 조건**

- 승리: **7일차** 도달 시 자본 ≥ 0 (일수는 임시)
- 패배: 하루 종료 시 자본 < 0

## 🔀 협업 방식

- **GitHub는 hermit만 사용**합니다. 이 repo가 유일한 원본(메인 프로젝트)입니다.
- 팀원은 각자 같은 Unity 버전 프로젝트에서 작업하고 **`.unitypackage`로 hermit에게 전달**합니다.
- hermit이 큰 틀과 핵심 시스템을 만들고, 팀원 패키지를 메인 프로젝트로 옮겨 통합합니다.
- 패키지 폴더 구조·네이밍·익스포트 방법은 👉 **[프로젝트 컨벤션](Docs/CONVENTIONS.md)** 을 반드시 따라 주세요.

## 🚀 시작하기

1. Unity Hub에서 **6000.3.27f2** 설치 (다른 버전 사용 금지 — 패키지 호환 문제 발생)
2. 이 repo를 클론하고 Unity Hub → **Add** → repo 루트 폴더 선택
3. 첫 실행 시 `Library/` 생성에 시간이 걸릴 수 있습니다.
4. 시작 씬: TBD (메인 메뉴 씬 확정 시 기재)

> 팀원은 repo 대신 hermit이 배포하는 **베이스 패키지**(`Base_vXX.unitypackage`)로 시작합니다. 자세한 내용은 [컨벤션 §2](Docs/CONVENTIONS.md#2-팀원-패키지-전달-규칙).
