> 현재 **확정된 사실만** 적습니다. 나머지는 팀 논의 후 채웁니다.

## 1. 확정 사항

### 개발 환경

| 항목 | 값 |
|---|---|
| Unity | **6.3 LTS (6000.3.27f2)** — 팀원 모두 같은 버전 사용 |
| 템플릿 | **Universal 2D** |
| 메인 메뉴 | [antfarmar/Unity-Game-Jam-Menu-Template](https://github.com/antfarmar/Unity-Game-Jam-Menu-Template) 기반 |
| 코딩 도구 | Cursor + Claude |

### 협업 방식

- **GitHub는 hermit만 사용**합니다.
- 팀원은 작업한 결과물을 **Unity 패키지(`.unitypackage`)** 로 hermit에게 전달합니다.
- hermit이 큰 틀과 핵심 시스템을 만들고, 팀원이 만든 작업물을 메인 프로젝트로 옮깁니다.

### 잼 규칙에서 오는 의무

- 외부 에셋(구매/무료)을 쓰면 라이선스를 확인하고 [CREDITS.md](CREDITS.md)에 기록합니다.
- 생성형 AI를 쓰면 [AI_USAGE.md](AI_USAGE.md)에 기록합니다. (제출 페이지 미기재 시 수상 제외)

### 참고: 확인된 Unity 동작 (논의 시 참고용)

- `.unitypackage`에는 **Tag, Layer, Sorting Layer 등 프로젝트 설정이 포함되지 않습니다.**
- 에셋의 연결 정보는 `.meta` 파일의 GUID로 유지되므로, 같은 에셋을 각자 따로 만들면 GUID가 달라져 참조가 끊길 수 있습니다.
- Export Package 창의 **Include dependencies** 옵션을 켜면 선택한 폴더 밖의 참조 파일도 함께 포함됩니다.
